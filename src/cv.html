Technological Stack: C#, XSD, XML Serialisation, .NET Standard, .NET Core, NuGet, Sandcastle, GitHub

  • Cross-Platform Compatibility: Engineered the package to support a massive ecosystem of target frameworks, including .NET Standard 2.0/2.1, .NET Core 3.0 up to .NET 10.0, and legacy .NET Framework 4.0+.
